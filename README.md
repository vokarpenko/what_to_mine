# What to mine?

Калькулятор доходности майнинга. Проект адаптирован для Android на Flutter **3.44.9 / Dart 3.12.2**. Версия Flutter закреплена в `.fvmrc`. iOS не входит в эту миграцию.

Google Play: https://play.google.com/store/apps/details?id=ru.vokarpenko.what_to_mine

## Подготовка Android

Нужны Flutter 3.44.9, JDK 17 или новее и Android SDK: Platform 36, Build Tools 36, NDK 28.2.13676358. Gradle 8.14.3 и Android Gradle Plugin 8.13.2 загружаются автоматически. Минимальная версия устройства — Android 7.0 (API 24).

В Android Studio откройте **Tools → SDK Manager → SDK Tools** и установите **Android SDK Command-line Tools (latest)**, если `flutter doctor` сообщает об их отсутствии. Затем выполните:

```sh
flutter doctor --android-licenses
flutter doctor -v
flutter pub get
flutter devices
```

При использовании FVM сначала выполните `fvm install`, а команды Flutter запускайте через `fvm flutter`.

## WhatToMine API

Приложение использует [официальный API WhatToMine](https://whattomine.com/api-docs):

- `GET /api/v1/coins` — монеты, сетевой хэшрейт и биржевые котировки;
- `GET /api/v1/gpus` — актуальный каталог GPU и их хэшрейты/энергопотребление;
- `GET /api/v1/algorithms` — резервный источник кодов алгоритмов; обычно достаточно `algo_param_name` из ответа `/coins`;
- `POST /api/v1/calculate` — суточная добыча, выручка и прибыль для всех выбранных алгоритмов одним запросом.

Все запросы передают `Authorization: Token …`. Старые обращения к Minerstat удалены.

### Добавление одного общего ключа

1. Войдите в аккаунт [WhatToMine](https://whattomine.com), подключите нужный тариф API и получите API token в личном кабинете. [Документация](https://whattomine.com/api-docs) описывает авторизацию и квоты; названия разделов личного кабинета могут меняться.
2. Скопируйте `what-to-mine-api.example.json` в `what-to-mine-api.local.json` в корне проекта.
3. Замените `YOUR_WHATTOMINE_TOKEN` реальным токеном:

   ```json
   {
     "WHAT_TO_MINE_API_KEY": "YOUR_WHATTOMINE_TOKEN"
   }
   ```

4. Запустите приложение:

   ```sh
   flutter run --dart-define-from-file=what-to-mine-api.local.json
   ```

В Android Studio: **Run → Edit Configurations… → Flutter → Additional run args**:

```text
--dart-define-from-file=what-to-mine-api.local.json
```

Либо передайте значение напрямую: `--dart-define=WHAT_TO_MINE_API_KEY=YOUR_WHATTOMINE_TOKEN`.

Для Android App Bundle:

```sh
flutter build appbundle --release --dart-define-from-file=what-to-mine-api.local.json
```

После изменения токена полностью остановите приложение и запустите заново. Токен задаётся при компиляции и используется также фоновыми задачами. Локальный JSON исключён из Git; пример содержит только заглушку. Этот вариант использует один общий ключ во всех установках одной сборки. Ротация ключей пока не реализована.

### Кеш и квота

Кеш сохраняется между запусками и используется фоновыми задачами:

| Данные | Срок актуальности |
| --- | --- |
| Результат расчёта для одинакового набора хэшрейтов, мощности и тарифа | 2 часа |
| Монеты и биржевые котировки | 24 часа |
| Каталог GPU | 7 дней |
| Резервный список алгоритмов, если в `/coins` не хватает кодов | 30 дней |

Изменение оборудования, мощности или тарифа требует нового расчёта. Одновременные одинаковые запросы объединяются; повторное ручное обновление в течение минуты использует кеш. Обычный запуск и переключение вкладок не принуждают сервер обновлять данные.

Проверка фоновых уведомлений настроена на **один раз в сутки** (1440 минут) и после включения, и после перезапуска приложения. Время последней попытки сохраняется до сетевого обращения: дополнительные callback-и, перезапуск и даже ошибка сети не вызывают новую проверку раньше чем через 24 часа. Уведомление отправляется, только если найдена положительная чистая прибыль. Android может откладывать фоновую работу; это не будильник на фиксированное время.

Фоновая проверка неизменной фермы требует ориентировочно до 62 запросов за 31 день: 31 расчёт и до 31 обновления монет. Использование приложения вручную, изменение оборудования/тарифа, добавление GPU, очистка данных и новые установки расходуют запросы отдельно.

### Сколько запросов тратится при входе

До оптимизации первый запуск загружал сразу монеты, алгоритмы и GPU, даже если вкладки каталогов не открывались. Теперь:

| Действие без актуального кеша | Запросы |
| --- | --- |
| Первый вход без выбранных GPU и пользовательских хэшрейтов | 1: `/coins` |
| Вход с сохранённой фермой | 2: `/coins` + `/calculate` |
| Повторный вход с актуальными котировками и расчётом | 0 |
| Нажатие «Добавить GPU» | 1: `/gpus`, далее кеш на 7 дней |

Вкладки создаются при первом открытии. Сам просмотр сохранённых GPU не загружает каталог. Имена и коды алгоритмов берутся из уже загруженного ответа `/coins`; `/algorithms` вызывается только при неполных метаданных. Ручное обновление по-прежнему может отправлять запрос, но повтор в течение минуты объединяется с предыдущим. В debug-логе строки `WhatToMine API: GET /…` / `POST /…` показывают именно реальные сетевые обращения; токен не выводится.

**Лимит 1000 запросов на ключ общий для всех устройств.** Локальный кеш не гарантирует соблюдение общего лимита при нескольких пользователях. Для публичного приложения с одним ключом потребуется серверный посредник с общим кешем и учётом квоты. Значение лимита берётся из ответа сервиса, а не предполагается равным 1000 для любого тарифа.

Ответы `X-RateLimit-Limit`, `X-RateLimit-Used` и `X-RateLimit-Remaining` сохраняются локально. При HTTP 429 приложение выдерживает `Retry-After`; без этого заголовка повторные сетевые запросы блокируются на сутки. Кешированные актуальные ответы остаются доступны. Ошибки 401/403, отсутствие токена и сетевые сбои показываются отдельно. Недоступный сервис не подменяется нулевой доходностью.

### Что изменилось в данных

- Убыточные варианты видны в списке доходности; уведомления о выгодном майнинге отправляются только при положительной чистой прибыли.
- Доходность берётся из текущих `estimated_rewards`, `revenue` и `profit`, возвращённых WhatToMine. Комиссия по умолчанию применяется сервисом; электричество уже вычтено из `profit` и повторно не вычитается.
- Выручка и прибыль отображаются в USD. На вкладке цен котировки из `/coins` переводятся из BTC в USD по публичному курсу Coinbase `GET https://api.coinbase.com/v2/exchange-rates?currency=BTC`. Курс загружается при первом открытии вкладки и кешируется на 24 часа; ключ не нужен, квота WhatToMine не расходуется. Ручное обновление может обновить курс, но не чаще раза в минуту. Биржевые объёмы в деталях доходности остаются в BTC. Цена берётся с биржи с наибольшим объёмом, объёмы суммируются. Монеты без цены и недоступный курс не подменяются нулевыми или BTC-значениями под заголовком USD.
- Прогноз на неделю/месяц остаётся линейной проекцией суточных значений на 7/30 дней, а не историей или гарантией дохода.
- Хэшрейты и мощность всех выбранных GPU суммируются по алгоритму с переводом в H/s. Названия из API сопоставляются с `param_name`; разные версии алгоритмов автоматически не объединяются.
- Сохранённые GPU и пользовательские хэшрейты остаются в существующей базе. Новый каталог имеет отдельные ID. Старые неподдерживаемые алгоритмы не отправляются в расчёт; если ни один выбранный алгоритм не поддерживается, приложение показывает ошибку. Для обновления профиля старой карты удалите её и добавьте модель из актуального каталога.
- Старый фильтр по USD-объёму удалён. Монеты с флагами `testing`/`lagging` исключены из расчётов. Для монет без биржевой цены показывается прочерк. Логотипы монет хранятся локально, без запросов к Minerstat и без сетевой загрузки при отображении.

### Логотипы монет и производители GPU

В приложение включены оригинальные логотипы всех **126 монет** из проверенного каталога WhatToMine. PNG/WebP и два SVG хранятся в `assets/icons/coins/`, а связь с ID монеты — в `coin_icon_assets.dart`. Источник каждого файла записан в `assets/json/coin_icons.json`. Иконки получены с [публичных страниц WhatToMine](https://whattomine.com/), без API-токена и расхода его квоты. Новая неизвестная монета получает обозначение буквами до следующего обновления набора иконок.

Обновление имеющихся логотипов:

```sh
python3 tools/sync_coin_icons.py --refresh
```

Для добавления новых монет можно передать сохранённый JSON-массив каталога: `--catalog /path/to/coins.json`. Скрипт обращается только к публичным страницам и CDN, API-ключ ему не нужен.

API часто возвращает имена без производителя: `GeForce RTX …`, `RTX A5000`, `Radeon RX …`. Производитель теперь определяется также по семейству модели, поэтому в выборе отображаются NVIDIA и AMD вместо ошибочного OTHER. Настоящие Intel/неизвестные модели не маскируются под NVIDIA или AMD.

## Проверки и генерация

```sh
flutter analyze
flutter test
dart run build_runner build --delete-conflicting-outputs
flutter build apk --debug
```

Floor 1.5 ограничивает версии генераторов: совместимый `built_value_generator` — 8.9.2. `pubspec.lock` хранится в репозитории. Генерация работает на Dart 3.12.2, но старый analyzer из зависимостей Floor сообщает о неполной поддержке языка 3.12. Не добавляйте `dependency_overrides` для обхода этих ограничений без проверки генерации и тестов.

APK находятся в `build/app/outputs/flutter-apk/`. Если `android/key.properties` отсутствует, release APK подписывается debug-ключом для локальной проверки. Для обновления приложения в Google Play нужен исходный upload keystore и корректный `android/key.properties`.
